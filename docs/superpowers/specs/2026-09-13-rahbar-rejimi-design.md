# Раҳбар режими (Rahbar mode) — дизайн

**Сана:** 2026-09-13
**Ҳолат:** ТАСДИҚЛАНГАН (фойдаланувчи 4 та қарорни танлади)
**Пилот:** Шовот тумани

---

## 1. Муаммо

Ҳозирги `mahalla_mobile` иловаси **фақат 5-лик/депутат** учун қурилган: иш рўйхати →
бино → зонага сурат олиш. Раҳбар (ҳоким, вилоят раҳбарияти) учун ҳеч нарса йўқ.

Раҳбар **маълумот киритмайди — фақат кўради.** Унга кераги:

1. Маҳаллада юрганида атрофда қандай бинолар/ташкилотлар борлигини **реал вақтда**
   билиш (3 км радиус, созланадиган).
2. Ҳозир турган маҳалласи ҳақида маълумот.
3. Туман кесимидаги ҳолат — рейтинг, устуворлик.

## 5. Архитектура

### 5.1 Роль модели (backend)

Ҳозир `VIEWER_ROLES = ['admin', 'viloyat']` — иккаласи ҳам `canSeeAll = true`.
**Туман даражасидаги кўрувчи йўқ.**

Янги рол:

```
'tuman' => ['dashboard.view', 'reports.view', 'houses.view', 'analyses.view']
```

`viloyat` билан **руxсатлари бир хил**, фарқи фақат **қамровда**:

| Рол | isAdmin | districtId | canSeeAll |
|---|---|---|---|
| `admin` | ✅ | null | ✅ |
| `viloyat` | ❌ | null | ✅ |
| **`tuman`** | ❌ | **профилдан** | ❌ |

### 5.2 Қамровни мажбурлаш — `ExecutiveScope`

**Бу дизайндаги энг хавфли жой.** Ҳозирги 8 та executive контроллери
туманни **умуман текширмайди** — чунки уларга фақат «ҳаммасини кўрадиган»
роллар кирарди. `tuman` ролини қўшишнинг ўзи **етарли эмас**: у ҳар қандай
туманнинг маълумотини сўраб ола беради.

Ечим — битта марказий синф `App\Domains\Mahalla\Support\ExecutiveScope`:

```php
final class ExecutiveScope
{
    /** Сўралган туманни ҳал қилади ёки 403. */
    public function district(User $user, ?string $requestedId): District;

    /** Маҳалла рухсат этилган туман ичидами — акс ҳолда 404. */
    public function mahalla(User $user, string $mahallaId): Mahalla;

    /** Танлагичда кўринадиган туманлар (null = ҳаммаси). */
    public function districtIds(User $user): ?array;
}
```

Хулқ-атвор:

| Ҳолат | `canSeeAll` (admin/viloyat) | `tuman` |
|---|---|---|
| Туман берилган, ўзиники | руxсат | руxсат |
| Туман берилган, бошқаники | руxсат | **403** |
| Туман берилмаган | конфигдаги стандарт (Шовот) | **ўз тумани** |
| Профилда туман йўқ | конфигдаги стандарт | **403** |
| Маҳалла бошқа туманда | руxсат | **404** |

> **Стандарт туманга қайтиш `tuman` учун ТАҚИҚЛАНАДИ.** Профилида туман
> кўрсатилмаган фойдаланувчига жимгина Шовот маълумотини бериш — айнан
> `NearbyController`да мутация тести билан фош қилинган нуқсон намунаси.
> Қамрови номаълум фойдаланувчи **ҳеч нарса кўрмайди**.

### 5.3 Мобил — роль бўйича иккита қобиқ

[`auth_gate.dart`](../../../../mahalla_mobile/lib/features/auth/auth_gate.dart) ҳозир
ҳамманы бир хил `HomeShell`га юборади. Шу ерда ажратилади:

```
AuthStatus.authenticated
  ├─ context.role ∈ {viloyat, tuman, admin} → RahbarShell   (янги, фақат кўриш)
  └─ акс ҳолда                              → HomeShell     (ўзгармайди)
```

**Read-only кафолати — архитектура даражасида:** `RahbarShell` дарахтидаги
ҳеч бир файл `features/capture/` ёки `features/upload/` дан import қилмайди.
Бу «тугмани яширдик» эмас — камера коди у ерга физик жиҳатдан етиб бормайди,
демак камера рухсати ҳеч қачон сўралмайди.

### 5.4 `RahbarShell` таблари

**1. Атроф** (асосий)
- GPS → «Сиз ҳозир: {туман}, {МФЙ}» картаси
- Радиус: 0.5 / 1 / **3** / 5 км
- `nearby` нуқталари + `boundary` полигони
- Қатламлар: Ижтимоий · Ташкилотлар · Уйлар · Мониторинг
- Нуқтага босилса — bottom sheet: кадастр, манзил, тури, ижтимоийми, мониторинг ҳолати

**2. Маҳалла** — турган маҳалла паспорти (GPSдан авто, қўлда ҳам)
- аҳоли, хонадон, оила, камбағаллик %, ижтимоий реестр
- обододнлаштириш ҳалқаси + матрица
- микро-лойиҳалар
- ижтимоий объектлар

**3. Туман** — рейтинг ва устуворлик
- маҳаллалар жадвали, ҳафталик рейтинг
- КОИ/ИПИ, A/B/C/D квадрантлар, «оғир» маҳаллалар

**4. Созламалар** — радиус, туман (агар `viloyat`), чиқиш

### 5.5 Харита — гибрид

- `flutter_map` + `latlong2` (мослик текширилди: 12 боғлиқлик тоза ўрнатилади)
- OSM плиткалар — веб SPA (`FeatureMap.vue`, `ChangeMap.vue`) айнан шуни ишлатади
- Плиткалар қурилмада кешланади; алоқа узилса кешдан ишлайди
- Кешда йўқ жой — оддий фон, лекин **бинолар ва чегара барибир чизилади**
  (улар бизнинг маълумотимиз, плиткага боғлиқ эмас)

## 6. Тегилмайдиган нарсалар

- `HomeShell` ва депутат оқими — **бир қатор ҳам ўзгармайди**
- `capture/`, `upload/`, зона кодлари, GPS/геофенс/сифат текширувлари
- Мавжуд `viloyat` ва `admin` роллари хулқи — регрессия тестлари билан қулфланади

## 7. Кўрсаткичлар (қачон тайёр деймиз)

1. `tuman` ролидаги фойдаланувчи ўз туманини кўради, бошқа туманга 403 олади —
   8 та эндпойнтнинг **ҳаммасида**, тест билан исботланган
2. Профилида туман йўқ `tuman` фойдаланувчи ҳеч нарса кўрмайди (стандарт туманга тушмайди)
3. `viloyat`/`admin` хулқи ўзгармаган (регрессия)
4. Раҳбар мобилда кириб, харитада ўз атрофидаги бинoларни кўради
5. Раҳбар иловасида «Сурат олиш» тугмаси ҳеч қаерда йўқ, камера рухсати сўралмайди
