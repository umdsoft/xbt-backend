# Маршрут ва навигация — фойдаланувчи топшириғи

**Сана:** 2026-09-14
**Ҳолат:** ҚАБУЛ ҚИЛИНДИ, навбатда (жорий иш — «Атроф аниқлиги» — тугагандан кейин бошланади)
**Манба:** фойдаланувчининг тўғридан-тўғри топшириғи

---

## Талаб

Фойдаланувчи харитадаги **52 та маҳалла пунктидан** бирининг маркерини босганда,
жорий GPS жойлашувидан танланган пунктгача **автомобиль йўллари орқали** борса
бўладиган реал маршрут харитада чизилиши керак.

## 1. Жойлашувни аниқлаш

- `geolocator` (лойиҳада бор) ёки мавжуд location пакети
- Android ва iOS учун permission'лар тўғри созилган бўлсин
- Рухсат берилмаса — тушунарли хабар + **«Рухсат бериш»** тугмаси
- Location Services ўчиқ бўлса — созламаларни очиш имконияти

> **Ҳозирги ҳолат:** `lib/core/geo/live_location.dart` да бу оқим аллақачон бор —
> `LocationFailure{serviceOff, denied, deniedForever, timedOut, error}` ва
> `_LocationFailureView` да «Созламаларни очиш» тугмаси. `AndroidManifest.xml` да
> `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` бор. **Қайта ёзилмайди** —
> фақат «Рухсат бериш» тугмаси қўшилиши ва iOS `Info.plist` матнлари текширилиши керак.

## 2. Маркерга босилганда

- Танланган пункт визуал ажралиб турсин
- Жорий координатадан пункт координатасигача маршрут ҳисоблансин
- Маршрут **тўғри чизиқ эмас**, мавжуд автомобиль йўллари бўйлаб
- Харита фойдаланувчи + пункт + бутун маршрутни экранга сиғдирсин

## 3. `RoutingService` — алоҳида қатлам

- MVP учун **OSRM API**
- API URL **конфигурацияда**, кодга hardcode қилинмайди
- Route geometry → `LatLng` нуқталарига айлантирилади
- `flutter_map` ичидаги `PolylineLayer` орқали чизилади
- Архитектура кейинчалик **OpenRouteService / GraphHopper** га осон алмашадиган бўлсин

## 4. Пастки маълумот панели

Маршрут чизилганда очилсин:
- танланган маҳалла пункти номи
- масофа (масалан: `2,4 км`)
- тахминий вақт (масалан: `6 дақиқа`)
- **«Йўналишни бекор қилиш»** тугмаси
- **«Навигацияни бошлаш»** тугмаси

## 5. Навигацияни бошлаш

- Телефондаги **Google Maps** иловаси очилсин
- `destination` сифатида танланган пункт координатаси
- Google Maps ўрнатилмаган бўлса — браузер орқали
- `url_launcher` ишлатилиши мумкин

## 6. Харита белгилари

- фойдаланувчи жойлашуви — **кўк** маркер
- танланган пункт — **алоҳида рангдаги** маркер
- маршрут — аниқ кўринадиган **кўк чизиқ**
- қолган маҳалла пунктлари мавжуд кўринишида қолсин

## 7. Ҳолатларни бошқариш

| Ҳолат | Хулқ |
|---|---|
| Маршрут юкланмоқда | loading индикатор |
| Интернет йўқ | «Интернет алоқаси мавжуд эмас» |
| Маршрут топилмади | «Ушбу пунктга йўналиш топилмади» |
| Бошқа маркер танланди | эски маршрут ўчирилиб, янгиси чизилади |
| Бекор қилиш босилди | polyline ва танланган пункт ҳолати тозаланади |
| Бир маркер бир неча марта босилди | **ортиқча API сўровлари юборилмасин** |

## 8. Код сифати (фойдаланувчи талаби)

- мавжуд лойиҳа архитектураси **аввал ўрганилсин**
- мавжуд саҳифа **бошқатдан ёзиб ташланмасин**
- код `service` / `model` / `UI` қисмларига ажратилсин
- null-safety талаблари
- **мавжуд функциялар ва дизайн ўзгармасин**
- API калитлари кодга очиқ ёзилмасин
- қўшилган пакетлар ва Android/iOS permission ўзгаришлари **тушунтирилсин**

## 9. Топшириш талаби

1. Ўзгартирилган файлларнинг тўлиқ коди
2. Янги яратилган файллар
3. `pubspec.yaml` га қўшиладиган пакетлар
4. `AndroidManifest.xml` учун permission'лар
5. iOS `Info.plist` учун location permission матнлари
6. Ишга тушириш ва текшириш бўйича қисқа кўрсатма
7. Мумкин бўлган хатолар ва уларни тузатиш усуллари

## Ойдинлаштирилди (фойдаланувчи жавоби, 2026-09-14)

**Савол:** маршрут маҳалла марказларигами ёки ҳозирги бино/ташкилот маркерларигами?

**Жавоб:** *«Har bir tumanni o'zini mahallalar sonidan kelib chiqib 1-variantni qil,
bu joyda 52 mahalla Shovot misolida olingan, aslida biz buni universal qilishimiz kerak»*

Демак:

1. **Иккаласига ҳам** маршрут чизилади — маҳалла марказларига ҲАМ, мавжуд
   бино/ташкилот маркерларига ҲАМ. Раҳбар ё умуман маҳаллага, ё аниқ мактаб/ҚВПга
   бора олсин.

2. **«52» ҚОТИРИЛМАЙДИ.** Бу Шовот мисоли. Маҳалла марказлари қатлами **турган
   туман** бўйича динамик олинади — туман алмашса, маркерлар ҳам алмашади.

   | Туман | Маҳаллалар |
   |---|---|
   | Шовот | 52 |
   | Бутун Хоразм | 509 (13 туман) |

   Манба: `master.mahallas.center_lat/center_lng` — **509 тасида ҳам тўлдирилган**
   (текширилган). Қамров `ExecutiveScope` орқали: `tuman` роли фақат ўз туманининг
   маҳалла марказларини олади.

   > Кодда ҳеч қаерда `52` ёки бошқа қотирилган сон бўлмасин. Тестда ҳам
   > «52 та келди» деб текширилмасин — «турган туманнинг барча маҳаллалари
   > келди» деб текширилсин, акс ҳолда бошқа туманда тест ёлғон гапиради.

3. Маҳалла марказлари **алоҳида қатлам** бўлсин — ёқиб/ўчириб бўладиган
   (мавжуд «Назорат · Ташкилотлар · Уйлар» чиплари ёнида).
