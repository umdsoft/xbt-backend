**Сана:** 2026-09-14

## 1. Талаб

Фойдаланувчи сўзи билан: *«хаританинг шу белгилаган жойида маълумот турсин, юрган жойига энг яқин қисмдаги объектлар тўғрисида маълумотлар келиб чиқиб туриши керак»* — ва учта қатлам: маҳалла паспорти, микро-лойиҳалар ҳолати, аёллар хатловидаги муаммолар.

Ҳозир «Атроф» экранида харита бутун майдонни эгаллайди; маълумот фақат тепадаги тор чизиқда ва нуқтага босилганда чиқади. Раҳбар юрганда — тўхтаб, экранга босиб, ўқиши керак. Бу «юрганда билиб бориш» эмас.

## 2. Маълумот ҳақиқати (2026-09-14 да ўлчанди)

**Бу дизайннинг энг муҳим қисми.** Учта қатламдан иккитасида production'да маълумот **йўқ**:

| Қатлам | Backend | Маълумот | Манба |
|---|---|---|---|
| Маҳалла паспорти | тайёр | ✅ **реал** (3255 аҳоли, 3.03% камбағаллик) | `master.mahalla_indicators` |
| Яқиндаги объектлар | тайёр | ✅ **реал** (Шовотда 36 268 бино) | `master.buildings` |
| Микро-лойиҳалар | тайёр | ❌ **0 та** бутун платформада | `mahalla.micro_projects` |
| Аёллар хатлови | тайёр | ❌ **0 аёл, 0 анкета** | `ayollar.*` |

Микро-лойиҳалар: ягона қатор 2026-07-21 да яратилиб **22 сониядан кейин ўчирилган** (қўл синови). Фаол: 0.

Аёллар: 509 та `mahalla_balances` қатори бор, лекин **ҳаммаси нол** — ҳар кечаги `BalanceRefresher` автоматик яратган бўш каркас. `staff` жадвалида **1 та** ҳисоб (администратор) — бирорта МФЙ фаоли киритилмаган.

**Хулоса:** бўшлиқ техник эмас, ташкилий. Иккала backend ҳам тўлиқ ишлайди.

### 2.1 Қарор: бўшлик яширилмайди

Фойдаланувчи танлади: **«Очиқ кўрсатилсин + масъул ёзилсин».**

Сабаби: раҳбар учун бўшлиқнинг ўзи маълумот. «Бу маҳаллада микро-лойиҳа қайд этилмаган» дегани ё ҳақиқатан ҳеч нарса қилинмаяпти, ё ҳоким ёрдамчиси ҳисобот бермаяпти — иккаласи ҳам раҳбар кўриши керак бўлган ҳолат. «Тайёрланмоқда» деб яшириш бу сигнални ўлдиради.

Шунинг учун бўш бўлим:
```
МИКРО-ЛОЙИҲАЛАР
Қайд этилмаган
Масъул: ҳоким ёрдамчиси
```
ЭМАС:
```
МИКРО-ЛОЙИҲАЛАР
Тайёрланмоқда…
```

## 3. Панел дизайни

### 3.1 Жойлашув (responsive)

Планшет 2560×1600 физик = **1280×800 dp**. Фойдаланувчи белгилаган соҳа ≈ 307 dp.

| Экран эни | Кўриниш |
|---|---|
| ≥ 900 dp (планшет) | **Ён панел**, чапда, қатъий **340 dp**; харита қолган жойни эгаллайди |
| < 900 dp (телефон) | **Тортиладиган пастки варақ** (`DraggableScrollableSheet`): кўриниш 0.18 → ярим 0.5 → тўлиқ 0.9 |

Ён панел харита устига **чиқмайди** — харита тор бўлади. Сабаб: ярим шаффоф қатлам харитани ҳам, матнни ҳам ўқиб бўлмас қилади.

### 3.2 Блоклар (тартиб мажбурий)

```
┌────────────────────────────────┐
│ 📍 АРЧАЗОР МФЙ          [📌]  │  1. Қаердаман
│    Шовот тумани · 3255 аҳоли   │
├────────────────────────────────┤
│ ⚠ ДИҚҚАТ                       │  2. Нима хавотирли (шартли)
│ • Мониторинг бошланмаган       │
│ • Микро-лойиҳа қайд этилмаган  │
├────────────────────────────────┤
│ ЯҚИНДАГИ ОБЪЕКТЛАР             │  3. Атрофда нима бор (ЖОНЛИ)
│ 🏫 32-мактаб            120 м  │
│ 🏥 ҚВП                  340 м  │
│ 🏛 МФЙ биноси           410 м  │
│                    [яна 162]   │
├────────────────────────────────┤
│ ПАСПОРТ                   ›    │  4. Маҳалла қандай
│ Камбағаллик      3.03%         │
│ Бандлик          —             │
│ [Оғир маҳалла]                 │
├────────────────────────────────┤
│ МИКРО-ЛОЙИҲАЛАР           ›    │  5. Бу ерда нима қилиняпти
│ Қайд этилмаган                 │
│ Масъул: ҳоким ёрдамчиси        │
├────────────────────────────────┤
│ АЁЛЛАР ХАТЛОВИ            ›    │  6. Ким ёрдамга муҳтож
│ Хатлов бошланмаган             │
└────────────────────────────────┘
```

**«ДИҚҚАТ» блоки — панелнинг юраги.** У фақат ҳақиқатан эътибор талаб қиладиган нарса бўлса кўринади. Ҳеч нарса йўқ бўлса — блок **умуман чиқмайди** («ҳаммаси яхши» шовқини қўшилмайди). Сигналлар:
- маҳалла `is_ogir = true`
- мониторинг бошланмаган (0 кузатув)
- микро-лойиҳа қайд этилмаган
- муддати ўтган лойиҳа бор (`planned_end < bugun`, `status ≠ done`)
- аёллар хатловида шошилинч ҳолатлар

### 3.3 Реал вақт хулқи

Бу — «юрганда билиб бориш» талабининг моҳияти:

| Ҳодиса | Оралиқ | Нима бўлади |
|---|---|---|
| GPS тик | ~12 м | «Яқиндаги объектлар» **клиентда** қайта тартибланади |
| Марказдан силжиш | радиус × 0.25 | Сервердан янги нуқталар |
| **Маҳалла алмашиши** | `current_mahalla.id` ўзгарса | **Бутун панел янгиланади** + «Сиз ЯНГИЙЎЛ МФЙга кирдингиз» хабари |
| 📌 босилса | — | Панел қотади; раҳбар бошқа маҳаллага ҳайдаганда ҳам ўша маҳаллани кўриб туради |

> **Масофа клиентда ҳисобланиши ШАРТ.** Сервер `distance_m` ни сўров пайтидаги марказдан беради; кейинги сўровгача 750 м юрилиши мумкин. Оралиқда рўйхат ёлғон масофа кўрсатади. `lib/core/geo/haversine.dart` даги `distanceMeters()` ҳар тикда қайта ҳисоблайди — 600 нуқта учун бу арзимас юк.

## 4. Аёллар кўприги

### 4.1 Нега янги эндпойнт

`tuman` роли Аёллар API'сига **кира олмайди**: Аёллар ўз RBAC'ига эга (`AyollarAccess`, `SYSTEM_CODE = 'ayollar'`), `EnsureAyollar` middleware `user_system_access` да `systems.code = 'ayollar'` қаторини талаб қилади. Маҳалла `tuman` фойдаланувчисида бундай қатор йўқ → ҳар сўровга **403**.

Ечим: кўприк **Маҳалла доменида** қурилади, Аёллар RBAC'ига умуман тегилмайди.

```
GET /api/mahalla/executive/mahallas/{mahalla}/ayollar-summary
```
- Гварди: мавжуд `mahalla.viewer` + `ExecutiveScope::mahalla()` (қамровдан ташқари → 404)
- Ўқийди: `ayollar.mahalla_balances` ва `ayollar.anketa_red_flags` — **фақат жамланма**
- Ҳеч қачон ўқимайди: `ayollar.women`, `anketas`, `households`, `work_plans`, `red_list`

### 4.2 Махфийлик — кичик сонларни яшириш

Аёллар байроқлари орасида **зўравонлик қурбони, вояга етмаган она, одам савдоси, пробация, наркология, профилактика ҳисоби** бор.

Кичик маҳаллада «зўравонлик қурбони: 1» — бу сон эмас, **шахсни очиб бериш**: қўшнилар кимлигини тахмин қилади. Бу расмий статистикадаги small-cell disclosure муаммоси.

**Ҳимоя:** нозик тоифаларда 5 дан кам бўлса аниқ сон берилмайди.

| Тоифа | Кўрсатиш |
|---|---|
| Нозик (7 та код), `count < 5` | `"<5"` (`suppressed: true`) |
| Нозик, `count >= 5` | аниқ сон |
| Оддий (6 та код) | аниқ сон |
| Жами | доим аниқ сон |

Нозик кодлар: `violence_victim, protection_order, minor_mother, probation, prevention_record, narcology_record, human_trafficking`.

> Чегара конфигурацияда (`config/mahalla.php` → `ayollar.small_cell_threshold`, дефолт 5). Керак бўлса ўзгартирилади, лекин дефолт ҳимояли.

### 4.3 Жавоб шакли

```json
{
  "mahalla": {"id": "uuid", "name": "АРЧАЗОР МФЙ"},
  "started": false,
  "period": {"year": 2026, "month": 9},
  "balance": {"total": 0, "green": 0, "yellow": 0, "red": 0, "status": "open"},
  "flags": [
    {"code": "chronic_illness", "label": "Сурункали касаллик", "count": 0, "suppressed": false}
  ],
  "urgent_total": 0
}
```

`started = false` бўлганда (`balance.total == 0`) мобил томон «Хатлов бошланмаган» ҳолатини кўрсатади.

### 4.4 `ayollar` уланиши

`main` тармоғида `config/database.php` да `ayollar` уланиши **йўқ** (у `deploy/ayollar` да). Қўшилади — `deploy/ayollar` даги билан **айнан бир хил** матн, акс ҳолда merge пайтида зиддият чиқади.

Локал дев базада `ayollar` схемаси мавжуд (14 жадвал), демак тестлар ишлайди. Лекин схема **йўқ бўлиши ҳам мумкин** (янги ўрнатиш) — эндпойнт бунда портламасдан `"available": false` қайтариши керак.

## 5. Тегилмайдиган нарсалар

- Аёллар домени, унинг RBAC'и, SPA'си, планшет иловаси — **бир қатор ҳам**
- `capture/`, `upload/` — алдовга қарши йўл
- Депутат `HomeShell` оқими
- Мавжуд `nearby` эндпойнти ва унинг қамров мантиғи

## 6. Кўрсаткичлар

1. Раҳбар маҳалла чегарасини кесиб ўтганда панел **ўзи** алмашади ва буни кўринарли қилади
2. «Яқиндаги объектлар» юрганда масофани янгилаб боради (сервер сўровисиз)
3. Бўш бўлимлар **масъулни номлаб** кўрсатади, «тайёрланмоқда» деб яширмайди
4. Аёллар бўлимида ҳеч қачон исм/манзил/ПИНФЛ чиқмайди; нозик тоифада `<5` яширилади
5. Планшетда ён панел, телефонда пастки варақ — иккаласида ҳам харита ишлатса бўлади
6. `tuman` бошқа туман маҳалласининг аёллар маълумотини **ололмайди** (404)
