### Task B3: Паспортга кўчалар, хонадонлар ва МФЙ биноси

**Файллар:** `app/Domains/Mahalla/Services/ExecutiveMahallaStats.php` (ёки паспортни
йиғадиган жой — аввал ўқи), `.../Api/Executive/MahallaDashboardController.php`,
`tests/Feature/Mahalla/...`

**Жавобга қўшилади** (мавжуд майдонлар ЎЗГАРМАЙДИ — веб SPA уларни ишлатади):

```json
{
  "streets_count": 3,
  "households_total": 564,
  "mfy_building": {
    "id": "uuid", "lat": 41.68, "lng": 60.33,
    "name": "МФЙ биноси", "address": "..."
  }
}
```
`mfy_building` — топилмаса **`null`** (41 маҳаллада шундай бўлади).

- [ ] `streets_count` — `master.streets` дан `mahalla_id` бўйича `count(*)`.
      `is_active` фильтри борми — жадвални текшир, бор бўлса ҳисобга ол.
- [ ] `households_total` — `master.buildings` дан `type = 'residential'` бўйича.
      **Диққат:** жавобдаги мавжуд `households` майдони `mahalla.houses` дан
      келади ва у **атайлаб тўлиқ эмас** (фақат мониторингга киритилганлар).
      Иккови ҲАР ХИЛ нарса — аралаштирма, иккисини ҳам қолдир.
- [ ] `mfy_building` — `buildings` × `object_types` (`code = 'mfy_binosi'`),
      шу маҳалладагиси. Бир нечта бўлса — биринчиси (`id` бўйича барқарор тартиб).
- [ ] Тестлар: кўчаси бор маҳалла · МФЙ биноси бор маҳалла (11 тадан бири) ·
      МФЙ биноси ЙЎҚ маҳалла → `null` · мавжуд майдонлар ўзгармаган (регрессия)

**Мутация:** `mfy_building` ни доим `null` қайтар → «бор» тести йиқилсин.

### Task M6: Панел тўлдириш + харита изоҳи + сайқал

**Файллар:** `lib/features/rahbar/executive_models.dart`, `context_panel.dart`,
`lib/features/map/map_legend.dart` (янги), `map_screen.dart`, тестлар

**1. Паспорт блокига қўшилади:**
```
ПАСПОРТ
Кўчалар          3
Хонадонлар       564
Камбағаллик      3.03%
Бандлик          —
```
`null` бўлса — `—` (мавжуд `formatNumber` ишлатилади, янгиси ёзилмайди).

**2. МФЙ биноси — алоҳида қатор:**
- Топилса: номи + масофа + босилса харитада марказлашади;
  харитада **алоҳида, ажралиб турадиган** маркер (бошқа `mfy_binosi`
  биноларидан ҳам фарқли — бу «шу маҳалланинг ўзиники»)
- Топилмаса: **«Кадастрда белгиланмаган»** + **«Маҳалла раиси белгилаши керак»**

**3. Рақамланган белгилар — тўлиқ изоҳ.**

Фойдаланувчи талаби: «рақамланган белгилар нимани англатишини тўлиқ ёзиб чиқиш».

Харитага **изоҳ (легенда)** қўшилсин — қатлам чиплари ёнида «?» тугмаси,
босилганда пастки варақ:

- **Рақамли доира (масалан «25»)** — шу жойда 25 та объект тўпланган.
  Босилса рўйхати очилади. Яқинлаштирсангиз алоҳида белгиларга бўлинади.
- **Ҳар бир иконка нимани англатади** — 20 тоифанинг ҲАММАСИ рўйхат
  билан: иконка + ранг + номи (Мактаб, Болалар боғчаси, ҚВП, Дорихона,
  МФЙ биноси, Савдо объекти, ...). Рўйхат `lib/core/object_types.dart`
  дан **автоматик** тузилсин — қотирилган такрор рўйхат ёзилмасин, акс
  холда иккови ажралиб кетади.
- **Ранглар**: ижтимоий объектлар (мактаб, ҚВП, дорихона, МФЙ...) ва
  тижорат объектлари фарқи.
- **Кўк нуқта** — сиз турган жой.
- **Пунктир чизиқ** — маҳалла чегараси.

**4. Сайқал ва нуқсонлар.** Фойдаланувчи «мукаммаллаштир, буг ва бошқа
нарсаларни тўғрла» деди. Аниқ топилганлар:

- Узун номлар рўйхатда кесилиб қоляпти («Курилиши тугалланмаган дала ш…»).
  Кесилган номга tooltip ёки босилганда тўлиқ кўрсатиш керак.
- Кластер варағидаги ном ҳам кесиляпти («Суний қопламали мини футбол
  майдончаси очиқ баскетбол майдончаси, са…»). Икки қаторга сиғдир.
- Кадастр номларида ортиқча тирноқ қолган (`"Автобекат ва дукон"биноси`) —
  кўрсатишда тозала (серверда ЭМАС, у ерда хом сақланади).

Бошқа нуқсон топсанг — ҳисоботда ёз, лекин **тузатишдан олдин** нима
эканини айт: мавжуд хулқни ўзгартириш фойдаланувчи кўрганини бузиши мумкин.

**Бузилмаслиги керак:** олти блок, `—` vs `0`, аёллар уч ҳолати, ДИҚҚАТ
блокининг бўш бўлса чиқмаслиги, масъулни номлаган бўш ҳолатлар, ҳар
бўлимнинг мустақил хато/қайта уриниш ҳолати, импорт тақиқи.
